# DataFrame Reporter

Проект содержит класс `DataFrameReporter`, предназначенный для быстрого анализа датафреймов Pandas.

Класс формирует отчёт, включающий:

- количество строк и столбцов;
- количество и долю дубликатов;
- количество и долю пропущенных значений;
- сводную статистику по числовым столбцам;
- сводную статистику по всем столбцам, если включён параметр `include_all`.

## Установка окружения

Создайте виртуальное окружение:
```bash
python3 -m venv venv
```
Активируйте его.
```bash
source venv/bin/activate
```
Установите библиотеки из файла requirements.txt:
```bash
pip install -r requirements.txt
```
## Запуск проекта

Запустите файл main.py командой:
```bash
python3 main.py
```
